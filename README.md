## About the Project

Originally released for the Sega Dreamcast and PlayStation 2, **Looney Tunes: Space Race** is an arcade racing game featuring iconic Looney Tunes characters competing across imaginative intergalactic tracks.

This project explores the possibility of bringing that experience to the **PlayStation Portable (PSP)** through a native C++ game engine adapted to the handheld's hardware architecture.

The main objective is to preserve the identity, gameplay mechanics and visual characteristics of the original game while addressing the PSP's processing, memory and graphical limitations.

Unlike traditional emulation, the project focuses on a native implementation designed specifically for PSP hardware.

## Development Goals

The project's primary objectives include:

- Native execution on PlayStation Portable hardware.
- Investigation and adaptation of original game assets and resource formats.
- Implementation of arcade racing mechanics and vehicle physics.
- Rendering optimized for the PSP Graphics Engine.
- Adaptation of gameplay controls to the PSP.
- Efficient memory management and performance optimization.
- Preservation of the original game's visual identity.
- Development of a gameplay experience suitable for portable hardware.

> [!NOTE]
> These are development goals, not confirmed completed features. Implementation details and the final scope may change throughout development.

## Hardware Compatibility

The project is primarily targeting PSP revisions equipped with **64 MB of RAM**:

| PSP Model | RAM | Development Target |
|-----------|-----|--------------------|
| PSP-1000 | 32 MB | Under evaluation |
| PSP-2000 | 64 MB | Primary target |
| PSP-3000 | 64 MB | Primary target |
| PSP Go | 64 MB | Under evaluation |
| PSP Street | 64 MB | Under evaluation |

Due to the PSP-1000's limited memory, additional optimizations may be necessary to achieve acceptable performance.

Compatibility, stability and actual hardware requirements have not yet been confirmed.
